# V3: trace rainfall

- Enter a nonnegative number with up to one decimal place, `T`, or leave blank.
- Lowercase `t` is normalized to `T` in the editor and API.
- `0.0` means no rain (white); `T` means rain whose quantity cannot be measured (white with a dark T).
- Blank values are missing reports/equipment faults (gray). U is not accepted.
- T counts as a report but is excluded from numeric maxima. A report without numeric values has no numeric maximum.
- Existing numeric thresholds and station coordinates are unchanged. No database schema migration or automatic historical data conversion is required.
- The A4 legend gains a T row and remains above the footer.

Validation: rainfall tests cover normalization, display, all numeric boundaries, mixed reports, all-T reports, and missing reports. Before production release, check authenticated save/reload and PNG/A4 download in a browser.
